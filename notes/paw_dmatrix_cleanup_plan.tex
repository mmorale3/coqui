\begin{abstract}
\noindent
Companion to \file{notes/paw\_implementation\_plan.md} (the phased build-out,
now historical). This is the \emph{corrective} plan: it defines the target
design for PAW/USPP in the self-consistent GW framework, records the audit
findings that motivate it, and sequences the work. All file:line references
are against the \code{paw} branch working tree on 2026-07-24. The guiding
requirements: no DFT contributions in the non-local $D$ matrix (except a
future, optional DFT-$V_{xc}$ core--valence term); a clean separation between
static (density-independent, built once at initialization) and dynamic
(density-matrix-dependent, built at matrix-element evaluation) terms; removal
of the QE \code{deeq} tensor; frozen core--valence exact exchange read from
file and added to the bare $D$; QE/ABINIT backend parity; both
moment-restored and shape-restored augmentation densities available and
correct; and, as the end goal, user-selectable evaluation routes for the
Hartree and exchange contributions to the HF/GW static self-energies ---
factorized ERIs (THC/Cholesky, today's only route) vs direct evaluation
through the \code{hamiltonian} routines --- which requires the two routes to
be a compatible partitioning of the same matrix elements.
\end{abstract}

\section{Design invariants (the contract everything below enforces)}
\label{sec:invariants}

For every augmented species (USPP and PAW), with projector channels $I,J$ on
atom $a$ of species $t(a)$, and CoQu\'i's self-consistent density matrix
$n_{s,\mathbf{k},ab}$ (never \code{mf.occ()}):

\subsection*{I1. One-center density matrix (becsum)}

A \emph{single} becsum definition used by all consumers (Hartree, deeq,
exchange, energies), symmetry-correct on any $k$-mesh:
\begin{keybox}
\begin{equation}
\becsum_a(I,J) \;=\; \frac{n_s}{N_k}
\sum_{s}\sum_{\mathbf{k}\in\mathrm{full\ BZ}}\sum_{ab}
P^{\mathbf{k}\,*}_{a,\,aI}\; n_{s,\mathbf{k},ab}\; P^{\mathbf{k}}_{b,\,aJ},
\qquad n_s = 2 \ \ (n_{\rm spin}{=}1,\ n_{\rm pol}{=}1),
\label{eq:becsum}
\end{equation}
\end{keybox}
with the full-BZ lift of the projections $P$ via the existing
atom-permutation + Wigner-$D$ + Bloch-phase machinery whenever
$N_k^{\rm IBZ} < N_k$.

\subsection*{I2. Static (frozen) per-atom $D$ --- built once at
\code{pseudopot} initialization, never mutated}

\begin{keybox}
\begin{equation}
\Dstat_{a}(I,J) \;=\; D^{0}_{t(a)}(I,J)
\;+\; \alpha_x\, E^{cv}_{t(a)}(I,J)
\;\;\big[\,+\ \text{future: DFT-$V_{xc}$ c--v term}\,\big].
\label{eq:dstatic}
\end{equation}
\end{keybox}

\begin{itemize}[leftmargin=1.6em]
\item $D^{0}$ is the \emph{full} frozen ionic $d^{0}_{ij}$:
\begin{equation}
D^{0}_{IJ} \;=\; \big(T^{\rm AE} - T^{\rm PS}\big)_{IJ}
\;+\; \big\langle \phi_I\phi_J \,\big|\, v_H[n_{Zc}] \big\rangle
\;-\; \big\langle \phit_I\phit_J + \Qhat_{IJ} \,\big|\, v_H[\tilde n_{Zc}] \big\rangle ,
\label{eq:d0}
\end{equation}
i.e.\ AE$-$PS kinetic difference plus the frozen-core--screened ionic
Hartree terms (including the compensation-moment piece on the PS side). QE's
UPF \code{dion} \emph{is} this object by convention; the ABINIT converter
assembles it (\code{assemble\_dij0}: \code{kinetic\_energy\_differences} +
$v_{H}[n_{Zc}]$/$v_{H}[\tilde n_{Zc}]$ matrix elements + moment term).
CoQu\'i does \emph{not} re-derive $D^0$ when the h5 provides it;
\code{compute\_paw\_static\_D} remains available as a cross-check tool only.
\item $E^{cv}$ = frozen core--valence exact exchange (\code{ex\_cvij}),
contracted with \textbf{factor 1} --- it is linear in the valence density
matrix and is captured through $e_{1e} = \mathrm{Tr}[D_m H_0]$, \emph{never}
through $\tfrac12\mathrm{Tr}[D_m K]$. Source order:
\code{Onecenter/ex\_cvij} if present; else built natively from
\code{Core/ae\_wfc} (\S\ref{sec:wsB}, item B3); else omitted with a loud
warning.
\item The DFT-$V_{xc}$ core--valence option (a DFT c--v XC term added to the
bare $D$) remains a declared-but-aborting enum value
(\code{cv\_exchange\_e::dft\_xc}) until implemented.
\item \textbf{No DFT XC and no QE-density quantities anywhere in
$\Dstat$.}
\end{itemize}

\subsection*{I3. Dynamic (density-dependent) per-atom $D$ --- Hartree only,
rebuilt at every matrix-element evaluation from the current $n$}

\begin{keybox}
\begin{equation}
D^{H}_{a}(I,J)[n] \;=\;
\int \! d^3r\; v_H\big[\bar\rho[n]\big](\mathbf{r})\, \Qhat_{a,IJ}(\mathbf{r})
\;+\; \Delta D^{H}_{a}(I,J)\big[\becsum[n]\big],
\label{eq:dh}
\end{equation}
\end{keybox}
where $\bar\rho$ = smooth density + compensation charge, and $\Delta D^{H}$
is the radial AE$-$PS one-center Hartree
(\code{compute\_paw\_hartree\_atom}; proper Hartree units,
$\code{rad\_fac}=1$, \textbf{valence-only}: no frozen-core densities enter
the dynamic radial Hartree --- the core--valence one-center electrostatics
is already inside $D^0$ (I2), and injecting $\rho_{\rm core}$ here
double-counts it ($+19.98$\,Ha $V_H$ trace excess on the AB semicore
fixture; root-caused and resolved 2026-07-25, guard
\code{ab\_direct\_vh\_trace\_split}). An earlier revision of this
parenthetical said ``frozen-core AE/PS core densities included'' --- that
is SUPERSEDED by the D2 resolution). For the full
KS-like operator the $\int V\,\Qhat$ piece uses $V_{\rm loc}+V_H$; for the
pure Hartree matrix it uses $V_H$ only. Both already exist in
\code{compute\_paw\_deeq\_from\_becsum}; they become the \emph{only} source
of density-dependent $D$.

\subsection*{I4. Exchange never enters $D$}

Valence--valence exact exchange lives in $v_x$ / the THC ERI, with two
selectable augmentation-density modes:
\begin{keybox}
\begin{itemize}[leftmargin=1.6em]
\item \textbf{\code{moment}} (default): moment-restored compensation charge
$\Qhat$ in the pair densities \emph{plus} the $\Delta C$ one-center
correction, prefactor $s_{\rm oc} = -1/N_k$. This is the
Fock-exact-one-center operator (ABINIT \code{pawdijfock} / VASP analogue).
\item \textbf{\code{shape}}: full AE$-$PS partial-wave pair density
($\phi\phi - \phit\phit$ form factors, \code{build\_qrad\_tab\_full\_aeps}),
$\Delta C$ \emph{dropped} (double-count otherwise), evaluated on the dense
grid. This is the Arnaud / GW-oscillator operator.
\item In \emph{both} modes core--valence exchange comes from $E^{cv}$ in
$\Dstat$ (Eq.~\ref{eq:dstatic}).
\end{itemize}
\end{keybox}
Both modes must be available and numerically correct in the direct $v_x$
path \emph{and} the THC ERI path. Hartree always uses moment restoration
(compensated smooth + radial one-center is already exact for Hartree ---
document, don't option-ize).

\subsection*{I5. $H_0$ and evaluation-path semantics}

\begin{keybox}
\begin{equation}
H_0 \;=\; T \;+\; V_{\rm loc}(\text{\code{pp\_local}})
\;+\; \sum_{a,IJ} \ket{\beta_{aI}}\, \Dstat_{a}(I,J)\, \bra{\beta_{aJ}} .
\label{eq:h0}
\end{equation}
\end{keybox}
$e_{1e} = \mathrm{Tr}[D_m H_0]$ is then purely static + frozen-core.
The nii/nij-vs-\code{nullptr} asymmetry in \code{add\_vpp\_impl} is
\emph{by design} and serves route selectability (I7): density-dependent
terms are added \textbf{if and only if} a density (\code{nii} or
\code{nij}) is passed.
\begin{itemize}[leftmargin=1.6em]
\item \code{nii = nij = nullptr}: Eq.~\eqref{eq:h0} only. Hartree and
exchange are supplied elsewhere (today: by the ERI objects orchestrated in
the SCF classes) and must \emph{not} appear here --- no QE deeq, no dynamic
$D$.
\item density passed: the requested density-dependent terms are added on
top of Eq.~\eqref{eq:h0}, under \emph{separate} boolean control for Hartree
and for exchange (new \code{add\_hartree} / \code{add\_exchange} flags on
\code{add\_vpp\_impl} and the public \code{add\_Vpp} overloads), so the
future \code{set\_H} can mix routes --- e.g.\ Hartree direct + exchange via
THC.
\item the \code{nii} and \code{nij} overloads must produce the identical
operator for the same physical density.
\end{itemize}
QE-eigenvalue reproduction is a \emph{diagnostic} that assembles
$\Dstat + D^H[n_{\rm QE}] + \int V_{xc}\Qhat$ explicitly --- it is not a
production path.

\subsection*{I6. Backend parity}

A QE-converted and an ABINIT-converted h5 for the same system must drive the
identical CoQu\'i code path, with no per-backend branches in
\code{pseudopot} beyond dataset presence (\code{ex\_cvij}, \code{Core/}).
Same datasets, same units, same index conventions.

\subsection*{I7. Evaluation-path equivalence (factorized ERIs vs direct)}

Today the Hartree and exchange contributions to the HF and static-GW
self-energies are built \emph{exclusively} from ERI objects (THC or
Cholesky), controlled in the SCF classes. The end goal is user choice: a
future \code{set\_H} routine will optionally assemble $V_H$ and/or
$\Sigma_x$ directly from the \code{hamiltonian} routines
(\code{add\_Vpp} with density + flags, \code{add\_Hartree},
\code{add\_exchange}), with the ERI route remaining available. The two
routes must therefore be a \emph{compatible partitioning of the same
Hamiltonian matrix elements}:
\begin{keybox}
\begin{equation}
J^{\rm ERI}_{ij}(s,\mathbf{k})[n] = J^{\rm direct}_{ij}(s,\mathbf{k})[n],
\qquad
K^{\rm ERI}_{ij}(s,\mathbf{k})[n] = K^{\rm direct}_{ij}(s,\mathbf{k})[n],
\label{eq:path-equiv}
\end{equation}
\end{keybox}
for every spin, $k$-point, and band pair --- up to converged ISDF
thresholds and compatible cutoffs. E.g.\ the HF build through the
PAW-enabled THC object must reproduce, element by element, the
\code{hamiltonian}-routine result. Eq.~\eqref{eq:path-equiv} is the
acceptance criterion for Workstream D and the gate for the future
route-selection project.

\subsection*{I8. All-electron orbital basis; identity overlap}

For PAW and USPP, HF and GW operate in the \emph{all-electron} orbital
basis: every matrix element ($H_0$, $V_H$, $\Sigma_x$, ERIs) is taken with
respect to the AE orbitals $\ket{\psi_i} = \hat{T}\ket{\tilde\psi_i}$,
which are orthonormal --- the overlap in all SCF/Dyson algebra is the
\textbf{identity}. The smooth orbitals + projector augmentation are only
the \emph{representation} of these AE matrix elements; \code{nii}/\code{nij}
are AE-basis density matrices, and the becsum of Eq.~\eqref{eq:becsum} is
the AE one-center density matrix. No $S$-matrix insertions appear in any
density contraction.

\section{Audit findings (what is wrong today)}
\label{sec:findings}

\subsection{\code{pseudopot} / matrix elements}

\begin{description}[leftmargin=2.6em,style=nextline]
\item[F1.] \textbf{QE \code{deeq} is read and used as the production $D$.}
\code{pseudopot.cpp:584} reads \code{deeq} into \code{Dnn\_atom}; QE deeq
$= d_{\rm van} + \int V_{\rm eff}\Qhat + \code{ddd\_paw}$ with
$V_{\rm eff} \supset V_{xc}$, and \code{pw2coqui} refreshes \code{ddd\_paw}
from the converged DFT density before export
(\file{pw2coqui.f90:213-219, 458-466}). DFT XC therefore enters $H_0$ twice
over. This is the central violation; removal is directed.

\item[F2.] \textbf{The three \code{add\_vpp} entry points are mutually
inconsistent} for USPP/PAW:
\emph{no-density} (production \code{set\_H0} for GW/scGW via
\file{gen\_one\_body\_hamiltonian.icc}): QE deeq + \code{ex\_cvij}
(\code{pseudopot.cpp:1308-1311});
\emph{nii}: native \code{compute\_paw\_deeq(nii, $V_{\rm loc}{+}V_H$,
include\_static=true)} --- no QE deeq, but also \textbf{no \code{ex\_cvij}}
(\code{pseudopot.cpp:1278-1293});
\emph{nij}: falls through to QE deeq again (\code{MAM FIX FIX FIX} at
\code{pseudopot.cpp:1277}, comment 1303--1307).
Same density $\Rightarrow$ three different Hamiltonians.
NB: the \emph{inclusion} asymmetry --- density-dependent terms only when a
density is passed --- is \emph{intentional} (route selectability, I5/I7).
The defects are that the tensors disagree: the no-density path must be
static-only (not QE deeq), and nij must build the same native dynamic $D$
as nii.

\item[F3.] \textbf{\code{ex\_cvij} placement is split.} Added to
\code{Dnn\_atom} in the ctor (\code{pseudopot.cpp:987-1007}) but absent from
\code{Dnn\_atom\_static\_paw} (\file{paw\_onecenter.hpp:388-413}), so (a) the
native \code{nii} path drops c--v exchange, and (b) \code{compute\_deeq\_scf}
does $\code{Dnn\_atom} = \text{static} + \text{Hartree}$ and would
\emph{erase} \code{ex\_cvij} from \code{Dnn\_atom} if ever called in
production (\file{paw\_onecenter.hpp:459-461}).

\item[F4.] \textbf{becsum symmetry is path-dependent.} The diagonal path uses
the full-BZ \code{compute\_becsum\_diagonal\_symm}; \emph{all} nij consumers
(\code{v\_h(nij)}, \code{compute\_paw\_deeq(nij)}, \code{compute\_deeq\_scf})
use the IBZ-weight \code{compute\_becsum\_full}
(\file{v\_h\_paw.hpp:147-148}), and \code{add\_Hartree(nij)} has no
$N_k^{\rm IBZ}{=}N_k$ guard ($v_x$'s nij overload does). Symmetry-reduced
mesh + full $D_m$ $\Rightarrow$ silently wrong compensation charge.
\code{compute\_becsum\_full} also truncates the imaginary part with only a
log (\file{v\_h\_paw.hpp:173-184}) instead of Hermitian pair symmetrization.

\item[F5.] \textbf{Static-ish work recomputed per call}:
\code{aainit\_tables\_build}, qrad tables, and the full-BZ Pskna lift are
rebuilt inside every \code{compute\_paw\_deeq} / $v_x$ call
(\file{paw\_onecenter.hpp:565}; \file{v\_x\_paw.hpp:397-413, 375, 740}); no
$\Delta k$-keyed Qfac cache. Known perf sink (direct $v_x$ went
hours~$\to$~27\,s after the uncommitted fixes; caching is the next step).

\item[F6.] \textbf{Spin handling}: deeq spin-collapse to $s{=}0$ and
$\code{vfull} = \code{svloc}(0,0,\cdot)+v_r$
(\code{pseudopot.cpp:600-603, 1285-1286}) --- magnetic LSDA $D$ is a
documented TODO; the refactor must leave a clean seam (per-spin $D^H$)
rather than bake $n_{\rm pol}{=}1$ deeper in.

\item[F7.] \textbf{Dead/legacy surface}: unused member
\code{memory::unified\_array qq} (\file{pseudopot.h:471}); \code{svsc} read
but unused in production paths; \code{skip\_pp} / \code{set\_kinetic}
diagnostic surface; \code{compute\_paw\_static\_D} unconsumed; stray
\file{.paw\_onecenter.hpp.swp}; no-op root check \code{pseudopot.cpp:699}.
The xml/\code{pw2bgw} init path is explicitly out of scope (user directive)
--- leave untouched.
\end{description}

\item[A1.] \textbf{Introduce the two-tensor model and delete
\code{Dnn\_atom}-as-QE-deeq.}

\item \code{Dnn\_atom\_static} (rename of \code{Dnn\_atom\_static\_paw}):

$+\;\alpha_x\,$\code{ex\_cvij} ($+$ the dft\_xc c--v term when it lands).

\item Remove the \code{deeq} read (\code{pseudopot.cpp:580-612}) and the

\item \code{compute\_paw\_deeq\_from\_becsum(include\_static)} pulls the

\item Delete \code{compute\_deeq\_scf}'s overwrite semantics: it becomes a

\end{itemize}

\item[A2.] \textbf{Align the \code{add\_vpp} paths with the I5 contract
(fixes F2).}
\begin{itemize}[leftmargin=1.4em]
\item no-density: \code{add\_vnl\_impl(\ldots, Dnn\_atom\_static)} --- $H_0$
is static-only per I5; Hartree/exchange come from the ERI objects in the
SCF classes (today's only route) and must not be double-counted here. This
\emph{changes} $e_{1e}$ for QE-sourced runs
(deeq's $V_H$/$V_{xc}$ content leaves $H_0$); the SCF/Dyson drivers already
add $V_H[n]$ via the ERI route, so total energies move to the

\code{scf\_driver} / \code{qp\_scf\_common} / \code{downfold\_1e} for
double-count or omission when this flips, and re-baseline the reference
energies in the test suite.
\item nii and nij: both call \code{compute\_paw\_deeq($n$,
$V_{\rm loc}{+}V_H$, include\_static=true)} $\Rightarrow$ identical operator
for identical density. The nij overload needs the symmetric becsum (A3).
\item add \emph{separate} boolean options \code{add\_hartree} /
\code{add\_exchange} to \code{add\_vpp\_impl} (threaded through the public
\code{add\_Vpp} overloads): the Hartree terms (smooth $V_H$ into
\code{hpsi} $+$ $\int V\Qhat$ $+$ radial $D^H$) are gated by
\code{add\_hartree}; the exchange contribution (band-pair augmented $K$,
today only reachable via \code{add\_exchange}) is inserted into \code{Hij}
when \code{add\_exchange} is set. This is the groundwork for the future
\code{set\_H} routine that mixes direct and ERI routes per term (I5/I7).
\item Remove the QE-deeq fallback warning path; a missing dataset now means
``old h5 file'' $\Rightarrow$ hard error naming the converter rerun.
